① Flavor scaffold — 15% done — MOST CRITICAL GAP
rabhan_config.dart CRITICAL
The flavor config class with supabaseUrl, anon key, oneSignalAppId, flavorName = 'rabhan', and all feature flags. Without this, feature flag guards don't work and the app can't initialize with the right Supabase project.
rabhan_theme.dart CRITICAL
ThemeData with background #080B12, primaryGreen #2EE59D, gold #D4A017, Cairo font, dark colorScheme. Currently the app renders with Moharek's theme.
main_rabhan.dart entry point CRITICAL
Separate main() that loads RabhanConfig, applies RabhanTheme, sets TextDirection.rtl, and calls the shared initializeApp(). Needed for flutter run --flavor rabhan -t lib/main_rabhan.dart.
Android productFlavors in build.gradle
rabhan flavor dimension, separate applicationId (com.yourcompany.rabhan), app name string. Without this, --flavor rabhan fails the Android build.
iOS scheme "Rabhan" in Xcode
Duplicate Runner scheme, set bundle ID com.yourcompany.rabhan, point to RabhanIcon asset set.
Cairo font in pubspec.yaml + assets/rabhan/ folder
Font family Cairo (Regular/Medium/Bold weights) declared under flutter.fonts. assets/rabhan/ folder with logo.png, logo_dark.png, splash.png.
RabhanFeature guard widget
A wrapper widget that reads flavorName from context and renders child only in the rabhan flavor. Needed to safely add Rabhan-only sections to shared screens without breaking Moharek.
RTL Directionality wrapper at app root
Wrap MaterialApp.router with Directionality(textDirection: TextDirection.rtl) for the Rabhan flavor. Affects all padding, row direction, icon flip, and text alignment.
Feature flag constants Missing
enableGrowthSystem, enableEcomMetrics, enablePackageTiers, enableAdCampaigns booleans in RabhanConfig. Used to conditionally show/hide entire feature areas.
